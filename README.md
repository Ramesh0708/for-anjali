# For Anjali

A small birthday website for [Anjali Singh](https://anjali.monster), a frontend engineer and UI/UX designer in Mumbai.

🌐 Live: [ramesh0708.github.io/for-anjali](https://ramesh0708.github.io/for-anjali/)

## What's inside
- A hero section and a short letter
- "Selected things", a look at her work
- A cake with three candles you can tap to light, then make a wish

## Tech stack
Plain HTML, CSS and JavaScript (`index.html`, `styles.css`, `script.js`). No build step.

## Run locally
Open `index.html` in a browser. The site is published with GitHub Pages.
