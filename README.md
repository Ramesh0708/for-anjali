# For Anjali

A small birthday website for [Anjali Singh](https://anjali.monster) — frontend engineer and UI/UX designer in Mumbai.

She asked, on X, for a little site made with her in mind. This is that page: a letter, a few of the projects worth naming out loud, and three candles.

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 4173
```

No build step. No tracker. The birthday date isn’t printed, because the post didn’t include one.
